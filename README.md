# TabGecko downloads

Windows installer, browser kernel packages and update metadata for [TabGecko](https://tabgecko.com).

[Download the latest release](https://github.com/Sucukdeluxe/tabgecko-releases/releases/latest)

Install `TabGecko-Setup-<version>.exe`. The application installs the separate Chromium and Firefox kernel packages itself and keeps them up to date. Each release also includes checksums and update metadata.

The Windows installer is not Authenticode-signed. Application and kernel updates are verified using signed metadata. See the release notes for the changes in each version.
